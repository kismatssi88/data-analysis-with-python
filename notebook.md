# How I Started

Before creating this repository, I learned the basics of **Python, NumPy, Pandas, and Matplotlib** from YouTube tutorials. While learning, I wrote down the syntax, functions, methods, attributes, and their uses in my notebook so I could quickly revise them whenever needed.

## Why I Created This Repository

After learning the basics, I realized that practice is the most important part of becoming better at data analysis.

I searched for beginner data analysis projects on YouTube and found the [Data Thinkers(youtube channel must try ) ]playlist. I have been using the datasets from that playlist to practice data cleaning, exploratory data analysis (EDA), and data visualization.

After working on only two datasets, I realized that doing all the data cleaning and visualization in regular Python scripts inside VS Code became difficult to manage. As the code grew longer, it became messy to experiment with different analyses and visualizations.

Because of this, I started using **Jupyter Notebook inside VS Code** from my third dataset onward. It made my workflow much cleaner and easier since I could run code cell by cell, visualize outputs instantly, and experiment without rerunning the entire script.

This repository documents my learning journey as I practice data analysis on different datasets. My goal is to improve consistently and track my progress from beginner to advanced.
